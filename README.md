## ✦ Overview

This portfolio is designed to present a modern technical identity with a "Panda Build" (High-Contrast Monochrome) workspace aesthetic. It serves as a centralized hub for engineering projects, programming certifications, and verified digital identity markers.

### Key Visual Highlights:
* **Pure Monochrome Identity:** Seamless switching between deep dark and high-contrast light mode, utilizing custom CSS design systems.
* **Stacked Hero Typography:** An elegant, bold layout emphasizing core developer disciplines directly on entry.
* **Zero-Framework Architecture:** Engineered purely from the ground up to ensure instantaneous load times and minimal CPU/RAM footprints.

---

## ✦ Core Features

### 1. Interactive Tabbed Filtering
An active filter showcase system driven by Vanilla JavaScript. Visitors can instantly filter through categories such as:
* **Projects:** Technical source code repositories and web applications.
* **Certificates:** Verified credentials and courses.
* **Achievements:** Academic and technical milestones.

### 2. Smart Form Interfaces
The contact section features an intuitive input field mechanism where interface icons dynamically adjust visibility (`opacity: 0`) the moment a user begins typing, maximizing workspace cleanliness. Includes a fully local, real-time reactive comment module.

### 3. Preloader Shutter System
A custom animated entry preloader utilizing a vertical "Slide-Up" shutter effect. Includes a synchronized bottom-up stagger for code icons and a centered typography reveal transition.

### 4. Fully Responsive Fluid Layout
Engineered with strict native CSS Media Queries. Includes an interactive single-button dropdown navigation system tailored specifically for mobile viewports, ensuring complete visual symmetry across desktop and mobile devices.

---

## ✦ Technical Stack

The architecture relies entirely on native browser technologies to keep the environment lean, secure, and fully transparent:

* **Structure:** HTML5 (Semantic and accessible markup)
* **Styling:** CSS3 (Custom Variables, Flexbox, CSS Grid, Media Queries)
* **Interactivity:** Vanilla JavaScript (ES6+ Native DOM Manipulation)
* **Icons:** Font Awesome Icons (Minimalist vector glyphs)
